# Landing Form Mini Project

## Project Overview

This project is a landing page created as part of the WEB-110 course. It follows the Chapter 9 guided project from the O'Reilly textbook and combines HTML and CSS skills learned throughout the first half of the course.

## Features

- HTML page structure and content
- Images and file paths
- HTML form elements and form controls
- CSS styling and selectors
- CSS Box Model
- Flexbox layout
- Responsive design using media queries

## Purpose

The purpose of this project is to practice combining HTML structure, CSS styling, forms, images, and responsive layouts to create a complete webpage.
